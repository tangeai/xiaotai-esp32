# P4 变更记录

## 1.3.0

- TiRTC SDK 升级至 2.5.0，更新静态库、头文件和构建契约。
- 新增 TGMP/KCP 建连诊断，显示实际初始化的协议、MTU 和发送缓存上限；连接建立后关闭底层诊断。
- 新增传输诊断主机检查，补充弱网排障与组件版本检查说明。

## 1.2.0

- 配网与绑定页面独立刷新，修正首次开机热点信息和绑定码显示延迟。
- 播放改用 ESP-DSP FIR 8→16 kHz 重采样和 15ms DMA 供音，完善跨包历史、尾音和待播量统计。
- AEC 后上行增益由 6 dB 调为标称 9.52 dB。
- 同站 HTTP 请求短时复用连接，错误、跨站和解绑时关闭连接。
- 更新唤醒模型与配套分类头，默认唤醒阈值调整为 0.90。
- 按业务上报音视频能力，体验和绑定入口改为 [xiaotai.chat](https://xiaotai.chat/)。
- 清理未使用的旧页面与资源。

## 1.1.2

- 配网新增 Wi-Fi 扫描、信号与加密状态显示、历史密码复用和隐藏网络输入。
- 保存最近 4 个成功联网的网络，备用 DNS 支持配置或关闭。
- 开机联网后先完成 SNTP 校时，再绑定、鉴权和上线。
- 增加联网准备提示，完善 ESP-Hosted 扫描数量、容量与空列表处理。
- 新增聆听、悠闲表情，扩展至 23 类表情、44 个姿态，调整眨眼与切换动作。

## 1.1.0

- 新增 TiRTC 多人语音对讲，支持房间密码、成员列表和按住讲话。
- NVS 存储改为异步，音量和静音操作改为非阻塞；界面忙时沿用上一帧。
- 新增有界 PCM 唤醒队列，隔离过期识别结果，完善 TFLM 卷积适配与连接内存管理。
- AI 连接就绪后立即握手，补齐 HTTP 组包失败处理与阶段日志。
- 源码、SDK、模型、资源与工具移入工程，支持独立构建。

## 1.0.0

- 首次发布 TiRTC/WebRTC 实时查看、音视频对讲、设备互呼、微信呼叫和 AI 对讲。
- 适配微雪 ESP32-P4-WIFI6-Touch-LCD-3.5，接入摄像头、屏幕、ESP-Hosted/C6 联网及 ES8311/AEC 音频链路。
- 摄像头按视频业务启停。
- 加入热点配网、六位码绑定、联系人、屏幕交互和“你好小钛”唤醒。
- 提供完整 16 MB 固件、烧录指南与校验文件。
