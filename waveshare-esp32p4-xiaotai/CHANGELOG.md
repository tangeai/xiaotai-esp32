# 版本记录

## 1.6.1

- 音频上行统一使用 Opus 16 kHz；H5 下行兼容 Opus 16 kHz 与 PCMA 8 kHz，统一重采样到 16 kHz 播放。
- 调整音频缓冲与增益，微信使用独立播放缓冲；优化视频会话中的音频连续性。
- H5/微信视频上行调整为 720×960、15 fps、目标 2 Mbps，固定传感器帧率并启用 50 Hz 防闪烁；修正 H.264 帧码率计算的无符号下溢。
- H.264 参考帧和全帧显示使用持久 PSRAM 缓冲，减少反复分配与显示拷贝。
- 绑定页支持验证码过期刷新和更换 Wi-Fi；界面读取缓存网络状态，避免查询阻塞绘图。
- 完善 C6 更新失败后的恢复操作；未获准 OTA 的同代固件保留原样并尝试联网，修正 ESP-Hosted 补丁在嵌套 Git 目录中的应用检查。

## 1.6.0

- 新增 C6 离线配套更新：P4 完整包内置 C6 APP，启动时检查兼容性，经 SDIO 更新并在重启后核验；目标版本跳过更新。
- 增加 C6 更新进度与恢复提示，联网和通话在 C6 检查完成后启动。
- ESP-IDF 升级至 5.5.5，ESP-Hosted 升级至 3.0.7，同步更新语音、音视频、摄像头和 LVGL 配套依赖。
- 调整启动初始化顺序，在 LVGL 锁内注册显示与触摸、设置旋转。
- 补齐源码构建所需的 ESP-NN P4 汇编与供应商编解码资源，并校验独立 C6 镜像输入。

## 1.5.0

- 芯片要求调整为 ESP32-P4 rev3.2 及以上，配套更新 400 MHz CPU、看门狗和 H.264 驱动配置。
- 修正摄像头 ISP 自动曝光、白平衡和图像高度配置；H5/微信视频目标码率提高至 3 Mbps，调整编码量化参数。
- 改善视频运行时的触摸响应，挂断、取消和拒接请求优先处理。
- TFLM 升级至官方 v1.4.1，使用其卷积通道修正，移除本地重复补丁。

## 1.4.1

- 完善 AI 对讲切换到 H5 实时查看时的连接交接，按连接代次隔离音视频订阅。
- 服务发现统一使用 HTTPS，TiRTC 与平台服务读取同一份发现结果；拒绝不安全的服务地址。
- 更新 TiRTC 2.5.0 补丁库，修正连接失败后的资源回收和 TURN 查询栈占用。
- 增加启动初始化进度提示，改善主页触摸响应；唤醒阈值调整为 0.95。
- 优化校时、HTTP 请求排队和空闲连接恢复；移除旧测试脚手架，将产品链接和 I2C 检查纳入构建。


## 1.4.0

- 按 H5 上下行流号和连接代次隔离媒体订阅。
- 更新 TiRTC 2.5.0 HTTPS 与反馈处理栈修复。
- 绑定入口统一为 xiaotai.chat；默认镜像限定为 P4 芯片 rev 1.0–1.99。

## 1.3.0

- TiRTC SDK 升级至 2.5.0，更新静态库、头文件和构建契约。
- 新增 TGMP/KCP 建连诊断，显示实际初始化的协议、MTU 和发送缓存上限；连接建立后关闭底层诊断。
- 新增传输诊断主机检查，补充弱网排障与组件版本检查说明。

## 1.2.0

- 配网与绑定页面独立刷新，修正首次开机热点信息和绑定码显示延迟。
- 播放改用 ESP-DSP FIR 8→16 kHz 重采样和 15ms DMA 供音，完善跨包历史、尾音和待播量统计。
- AEC 后上行增益由 6 dB 调为标称 9.52 dB。
- 同站 HTTP 请求短时复用连接，错误、跨站和解绑时关闭连接。
- 更新唤醒模型与配套分类头，默认唤醒阈值调整为 0.90。
- 按业务上报音视频能力，体验和绑定入口改为 [xiaotai.chat](https://xiaotai.chat/)。
- 清理未使用的旧页面与资源。

## 1.1.2

- 配网新增 Wi-Fi 扫描、信号与加密状态显示、历史密码复用和隐藏网络输入。
- 保存最近 4 个成功联网的网络，备用 DNS 支持配置或关闭。
- 开机联网后先完成 SNTP 校时，再绑定、鉴权和上线。
- 增加联网准备提示，完善 ESP-Hosted 扫描数量、容量与空列表处理。
- 新增聆听、悠闲表情，扩展至 23 类表情、44 个姿态，调整眨眼与切换动作。

## 1.1.0

- 新增 TiRTC 多人语音对讲，支持房间密码、成员列表和按住讲话。
- NVS 存储改为异步，音量和静音操作改为非阻塞；界面忙时沿用上一帧。
- 新增有界 PCM 唤醒队列，隔离过期识别结果，完善 TFLM 卷积适配与连接内存管理。
- AI 连接就绪后立即握手，补齐 HTTP 组包失败处理与阶段日志。
- 源码、SDK、模型、资源与工具移入工程，支持独立构建。

## 1.0.0

- 首次发布 TiRTC/WebRTC 实时查看、音视频对讲、设备互呼、微信呼叫和 AI 对讲。
- 适配微雪 ESP32-P4-WIFI6-Touch-LCD-3.5，接入摄像头、屏幕、ESP-Hosted/C6 联网及 ES8311/AEC 音频链路。
- 摄像头按视频业务启停。
- 加入热点配网、六位码绑定、联系人、屏幕交互和“你好小钛”唤醒。
- 提供完整 16 MB 固件、烧录指南与校验文件。
