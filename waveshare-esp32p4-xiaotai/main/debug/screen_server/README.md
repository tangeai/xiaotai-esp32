# 旧 Monitor 屏幕调试服务

本目录保留上游实现，不是小钛当前屏幕调试入口。当前 [main/CMakeLists.txt](../../../main/CMakeLists.txt) 和产品组件没有把旧 Monitor 屏幕服务纳入产品组合；不要只改旧开关就假定当前固件提供 8080 服务。

旧路由、控制接口说明已移到仓外历史资料。本目录代码保留供旧实现对照，未接入当前产品构建。

后续确需屏幕采样或自动化控制时，先按[测试与排障](../../../docs/TESTING.md)核对所有权和隐私，获得操作安排后使用仓外私有工具。不要为调试替换产品 UI 或增加默认常驻服务。
