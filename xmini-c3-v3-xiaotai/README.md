# 小钛 Xmini-C3-V3

基于 **TiRTC / WebRTC** 的小屏语音终端，提供 AI 对话、微信语音通话、设备互呼、网页实时语音和多人对讲。适用于 **Xmini-C3-V3 / ESP32-C3 / 16 MB Flash**，当前版本 **0.1.0，体验候选**。

设备通过 BOOT 单键操作中文菜单，使用 ES8311 麦克风与扬声器进行双向语音。音频格式为 **G.711 A-law（PCMA）、8 kHz、单声道、20 ms / 160 字节**；不提供视频、Opus 或 OTA。

## 先体验

从[本版本发布页](https://github.com/tangeai/xiaotai-esp32/releases/tag/xmini-c3-v3-app-v0.1.0)下载完整 16 MB BIN、`FLASHING_CN.md` 和 `SHA256SUMS.txt`，按下文烧录后配网、绑定即可使用，无需先安装编译环境。

**完整包会清除设备的 Wi-Fi、绑定身份和设置。** 只用于 Xmini-C3-V3，不能与旧 Xmini-C3、C3-4G、MZ28 或 S3/P4 固件混用。需要保留现有配置时，先核对分区，再使用固件 ZIP 中的 APP 分段；不要整片擦除。

## 用浏览器烧录

1. 用 USB 数据线连接开发板，关闭占用串口的程序。在电脑 Chrome/Edge 打开[乐鑫在线烧录工具](https://espressif.github.io/esptool-js/)。
2. 点击 **Connect**，选择设备串口并确认 ESP32-C3。连接失败时，按住 BOOT、点按 RESET，再松开 BOOT。
3. 添加完整 `full-16MB.bin`，地址填写 **`0x0`**。Flash Mode、Frequency、Size 选择 **`keep`**，点击 **Program**，等待写入和校验完成后复位。

完整包为 **16,777,216 字节**，DIO / 80 MHz。不要把单独的 APP BIN 写到 `0x0`。容量、校验和保留配置升级见[详细烧录说明](docs/FLASHING.md)。

## 配网与绑定

1. 首次启动后，用手机连接屏幕显示的 `XiaoTai-XXXX` 热点，打开 `http://192.168.6.1`，填写可上网的 2.4 GHz Wi-Fi。
2. 等待设备验证网络、保存配置并重启。密码错误时修改后重试；成功保存前不要断电。
3. 在[小钛平台](https://xiaotai.chat/)的[我的设备](https://xiaotai.chat/devices)中添加设备，输入屏幕显示或语音播报的六位验证码。双击 BOOT 可重播有效验证码。
4. 如需微信通话，另在“小钛”微信小程序完成通话授权，再刷新设备联系人。平台归属绑定与微信通话授权是两个步骤。

## 一个按键怎么用

| 操作 | 用途 |
| --- | --- |
| 单击 BOOT | 选择下一项 |
| 双击 BOOT | 确认当前项 |
| 长按 BOOT 约 1.2 秒 | 返回上一页；会话中请求拒绝或结束，收尾后回首页 |

主页保留 **AI / WX / DEV / SET** 四个入口。会话未结束前，先等待设备返回空闲状态，再切换功能。

| 想做什么 | 从哪里进入 |
| --- | --- |
| AI 对话 | AI，进入后按页面提示对话 |
| 微信通话 | WX，刷新并选择已授权联系人；来电时按页面选择接听或拒绝 |
| 设备互呼 | DEV，选择联系人；联系人申请需明确接受或拒绝，返回不会代替处理 |
| 多人对讲 | DEV → 多人对讲，创建或加入房间；六位房号，密码房另填四位密码 |
| 网页语音 | DEV → 实时语音，再从平台发起语音连接；不提供视频 |
| 音量、麦克风与语音引导 | SET，修改后等待保存 |
| 更换 Wi-Fi | SET → 重新配网，确认后重新配置；保留绑定身份 |

出厂默认音量为 **40**、麦克风增益为 **24 dB**。可按现场环境调整；完整烧录会恢复这些默认值，不沿用旧设备已保存的设置。

## 使用提示

- 设备结束对讲后，网页连接状态可能未及时刷新。
- 体验候选适合在受控环境集成验证；开放配网热点与默认未加密 NVS 的风险需在产品部署前评估。
- 不使用生产凭据。API、MQTT 与 RTC 的传输认证需分别核对，HTTPS 服务发现不代表全部 RTC 链路已认证 TLS。
- 现有证据包含当前 APP 的双机语音提示、AI、设备互呼和设备侧网页退出验证；微信长按挂断为用户验收。完整包首次安装、群聊扩展回归、弱网和长稳不据此宣称通过。
