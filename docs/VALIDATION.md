# 验证范围与已知限制

多芯片分支提供源码预览，不提供可直接烧录的固件。本页用于判断哪些结果可复用，以及修改后需要补哪些检查。

## 已有构建证据

| 受测版本 | 构建与主机检查 | 适用范围 |
| --- | --- | --- |
| 2026-11-03 六板迁移基线 | 六板默认产品完整编译、链接通过 | 只对应当时的 SDK、配置和源码 |
| 2026-11-05 V0.1.0 开发基线 | 六板 SDK 链接探针、45 个主机测试程序、立创 S3 普通与诊断固件构建通过 | 其他五板未在该基线上重做整机构建；SDK 探针不能代替固件构建 |
| 多芯片源码预览 | 六板构建参数预检通过 | 未重新编译或烧录，未完成六板真机验收 |

早期立创 S3 试验固件的启动、联网和部分媒体检查不等于当前源码的真机结果。

## 使用限制

- **选板与配置：** 只支持已登记的默认产品组合。现有代码仍有板型绑定，不能靠换板名或关闭若干功能完成移植。详见[兼容性契约](新板适配与兼容性契约.md)。
- **SDK 与网络：** 立创 S3 专用 SDK 的 HTTP-only 限制仅作用于 TiRTC SDK 服务路径。Xmini 的 Mini 变体仍有 `VERIFY_NONE` 和连接生命周期等已知限制，详见 [SDK 说明](../components/tirtc_sdk/variants/xmini/README.md)；不能以主机检查作为生产安全验收。
- **资源与媒体：** 立创 S3、WT99 的应用分区余量需按实际构建复核。音视频、显示和触摸、重连、弱网与长稳都需要在目标板单独验证。

## 复验入口

按[多芯片适配指南](MULTI_CHIP.md)选板，再按改动范围运行检查：

```sh
python scripts/check_structure.py
python tests/test_product_contracts.py
python tests/test_build_profiles.py
```

完整主机回归入口是 `python tests/run_host.py`，环境和前置依赖见[架构开发指南](架构开发指南.md#5-提交前检查与适配完成标准)。公共接口变更应覆盖使用该接口的所有板型；真机结果与主机、构建结果分别记录。
