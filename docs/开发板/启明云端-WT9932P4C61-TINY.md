# 启明云端 WT9932P4C61-TINY

[开发板列表](README.md) · [快速开始](../快速开始.md) · [门禁](../功能/门禁.md)

ESP32-P4 主芯片加 ESP32-C61 联网芯片的小板，带一个摄像头和 BOOT 键。小钛在它上面是一台**没有屏幕的门铃室外机**：放在门口，访客按 BOOT 键就呼叫屋里的室内机，室内机能随时查看门口的画面。

| 项目 | 内容 |
| --- | --- |
| 芯片 | ESP32-P4（芯片版本 rev3.1 及以上），Wi-Fi 由板上的 ESP32-C61 提供（4 线 SDIO） |
| 摄像头 | SC2336，1024×600，每秒 30 帧 |
| 按键 | BOOT 键：按一下呼叫屋里 |
| 声音 | 板上没有麦克风和喇叭，通话只有画面 |
| 产品名 | `xiaotai-wt9932p4c61-tiny` |
| 烧录时的芯片名 | `esp32p4` |

## 怎么用

这块板没有编好的固件：按[第一次编译](../第一次编译.md)准备 ESP-IDF 6.0，运行 `python scripts/build.py wt/wt9932p4c61-tiny`，再烧录。下载页上的「启明开发板 · ESP32-P4」是 [WT99P461-S1](WT99P461-S1.md) 的固件，不能用在这块板上。

1. **配网**：串口输入 `wifi-set <Wi-Fi 名称> <密码>`，或者连它开出的热点在网页里填，见[串口命令](../AT指令.md)和[配网与绑定](../功能/配网与绑定.md)。
2. **绑定**：串口发 `AT+BIND` 读验证码，在小程序里添加设备时填进去。
3. **配对**：在室内机（可视门铃或门禁室内机）上把这台设备加为门口的设备，查看一次门口。以后按 BOOT 键就呼叫这台室内机。
4. **按铃**：按一下 BOOT 键，依次呼叫查看过它的室内机，每台 30 秒；呼叫中再按一下不呼了，通话中按一下挂断。

按键在每种情况下做什么、谁能查看和开门，见[门禁](../功能/门禁.md#没有屏幕的门铃室外机)。

## 给开发者

| 项目 | 内容 |
| --- | --- |
| 编译 | `python scripts/build.py wt/wt9932p4c61-tiny` |
| 产品清单 | `products/xiaotai-wt9932p4c61-tiny/product.json`，应用只有 `doorbell` |
| 板包 | `boards/wt/wt9932p4c61-tiny/` |
| 串口 | UART0，115200；`AT+STATUS app.doorbell` 读按铃、呼叫、接听、查看的次数 |
| 声音 | 板包用无声的音频设备（`xiaotai_audio_silent_create`）：通话和媒体引擎照常运行，收到的是静音，发出的声音被丢掉。以后接上麦克风和喇叭时，换成真正的音频设备就行 |
| 联网芯片 | C61 跑 ESP-Hosted，复位脚 GPIO13 高电平有效；SDIO：CLK 18、CMD 19、D0–D3 14–17 |
| 摄像头 | 电源 GPIO0（开机先断 50 ms 再上电，等 150 ms），SCCB 走 I2C0：SDA 7、SCL 8 |
| 没有用到的 | 板上的 RGB 灯（GPIO51）和可选的屏幕 |
