# GUITION JC1060F570C

[开发板列表](README.md) · [快速开始](../快速开始.md) · [使用说明](../使用说明.md)

7 寸 1024×600 触摸屏，主芯片是 ESP32-S31。它是五块板里屏幕最大的一块，没有摄像头。

| 项目 | 内容 |
| --- | --- |
| 芯片 | ESP32-S31 |
| 屏幕 | 7 寸 1024×600 触摸屏 |
| 摄像头 | 无 |
| 固件关键字 | `jc1060f570c` |
| 烧录时的芯片名 | `esp32s31`（只在用命令行烧录时要填） |
| 烧录和看日志用的 USB 口 | 板上的 USB-C 口（芯片原生 USB） |

## 功能

AI 对话、设备对讲、微信通话、多人对讲、实时查看（声音）、声音识别、闹钟和倒计时。界面和立创实战派 S3 相同，按大屏重新排版。

## 烧录

按[快速开始](../快速开始.md#2-烧录)的步骤做，下面是这块板要注意的：

- **固件文件**：在 [Releases](https://github.com/tangeai/xiaotai-esp32/releases/latest) 的 Assets 列表里下载 `v<版本>_jc1060f570c_idf6.1_merged.bin`，`<版本>` 是最新的版本号，例如 `v0.3.1_jc1060f570c_idf6.1_merged.bin`。这块板只有 `idf6.1` 一个文件。
- **命令行烧录**：芯片名写 `esp32s31`，要用认识这款芯片的 esptool；ESP-IDF 6.1 自带的版本可以。
- **下载模式**：芯片等待电脑写入固件的状态。这块板不用手动进，烧录工具会让芯片自动进入。

烧录完成后屏幕出现「连接 Wi-Fi」页，说明烧录成功，接着按[快速开始](../快速开始.md#3-配网)配网和绑定。屏幕没有变化时，拔掉 USB 线再插回去；仍然黑屏或不停重启，看[常见问题](../常见问题.md#烧录)。
