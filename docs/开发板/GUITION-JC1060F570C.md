# GUITION JC1060F570C

[开发板列表](README.md) · [快速开始](../快速开始.md) · [使用说明](../使用说明.md)

7 寸 1024×600 触摸屏，主芯片是 ESP32-S31。它是五块板里屏幕最大的一块，没有摄像头，适合放在室内：看门口、对话、看时间。

| 芯片 | ESP32-S31 |
| 屏幕 | 7 寸 1024×600 触摸屏 |
| 摄像头 | 无 |
| 固件关键字 | `guition-esp32s31` |

| 烧录和看日志用的 USB 口 | 板上的 USB-C 口（芯片原生 USB） |

## 功能

AI 对话、设备对讲、微信通话、多人对讲、实时查看（声音）、声音识别、闹钟和倒计时。待机页和对讲页上是[屏幕人物](../功能/屏幕人物.md)。

也能当[门禁](../功能/门禁.md)，四种模式各是一页，左右翻就到，停在哪一页（两秒，或点了这一页上的按钮）就按哪种接来电：

- **可视门铃**、**门禁室内机**：放在家里，查看门口时全屏显示门口的画面，微雪 P4、WT99、立创实战派 S3、CoreS3-Lite 当室外机都能看到；
- **门铃室外机**：装在一户门口，访客按铃呼叫室内机，室内机查看时听得到门口的声音。没有摄像头，只有声音；
- **门禁机**：装在单元或大门，首页是数字键盘，访客拨房号找住户。同样只有声音。

和别的设备视频通话时只看对方的画面。微信的视频来电按语音接听。

左右翻页换首页：人物、门禁的四页、闹钟。从人物头顶开始的横划是摸头，别处都是翻页。

## 烧录

按[快速开始](../快速开始.md#2-烧录)的步骤做，下面是这块板要注意的：

- **固件文件**：在 [Releases](https://github.com/tangeai/xiaotai-esp32/releases/latest) 的 Assets 列表里下载 `v<版本>_guition-esp32s31_merged.bin`，`<版本>` 是最新的版本号，例如 `v0.5.0_guition-esp32s31_merged.bin`。
- **命令行烧录**：芯片名写 `esp32s31`，要用认识这款芯片的 esptool；ESP-IDF 6.1 自带的版本可以。
- **下载模式**：芯片等待电脑写入固件的状态。这块板不用手动进，烧录工具会让芯片自动进入。

烧录完成后屏幕出现「连接 Wi-Fi」页，说明烧录成功，接着按[快速开始](../快速开始.md#3-配网)配网和绑定。屏幕没有变化时，拔掉 USB 线再插回去；仍然黑屏或不停重启，看[常见问题](../常见问题.md#烧录)。
