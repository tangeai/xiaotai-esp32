# 开发板

[文档地图](../README.md) · [快速开始](../快速开始.md)

小钛支持五块带触摸屏的开发板。先认准型号，再从表里点进对应的页面：页面上有这块板的 USB 口、下载模式、固件文件和它特有的功能。

## 先认准型号

- 看板子背面印的字、包装或购买记录，核对**完整型号**。只知道“ESP32-S3”或“ESP32-P4”不够，那是芯片的名字。
- 微雪 P4 的 3.5 寸和 4.3 寸是两块不同的板。这里支持的是 3.5 寸。
- M5Stack 要确认是 CoreS3-Lite。
- 两块 P4 板要求芯片版本 rev3.1 及以上。用 esptool 连接板子时，输出里会显示芯片版本。

## 支持的板

| 开发板 | 芯片 | 屏幕 | 摄像头 | 固件关键字 | 可用的 ESP-IDF |
| --- | --- | --- | :-: | --- | --- |
| [立创实战派 ESP32-S3](立创实战派-S3.md) | ESP32-S3 | 320×240 | 有 | `szpi-s3` | 6.0、5.5 |
| [M5Stack CoreS3-Lite](M5Stack-CoreS3-Lite.md) | ESP32-S3 | 320×240 | 有 | `cores3-lite` | 6.0、5.5 |
| [微雪 ESP32-P4-WIFI6-Touch-LCD-3.5](微雪-P4-3.5寸.md) | ESP32-P4 + C6 | 480×320 | 有 | `waveshare-p4-rev3` | 6.0、5.5 |
| [WT99P461-S1](WT99P461-S1.md) | ESP32-P4 + C61 | 1024×600 | 有 | `wt99p461-s1-1v1` | 6.0、5.5 |
| [GUITION JC1060F570C](GUITION-JC1060F570C.md) | ESP32-S31 | 7 寸 1024×600 | 无 | `jc1060f570c` | 6.1 |

最后一栏是编译这块板的固件可以用的 ESP-IDF 版本。只是下载固件来烧的话不用管它，按下面“固件文件怎么找”的规则选文件。

## 每块板能做什么

| 开发板 | AI 对话 | 设备对讲 | 微信通话 | 多人对讲 | 实时查看 | 这块板还有 |
| --- | :-: | :-: | :-: | :-: | :-: | --- |
| 立创实战派 ESP32-S3 | ✓ | ✓ | ✓ | ✓ | 画面和声音 | AI 看图、声音识别 |
| M5Stack CoreS3-Lite | ✓ | ✓ | ✓ | ✓ | 画面和声音 | 声音识别 |
| 微雪 ESP32-P4 3.5 寸 | ✓ | ✓ | ✓ | ✓ | 画面和声音 | 视频通话、门禁室内机 |
| WT99P461-S1 | ✓ | ✓ | ✓ | ✓ | 画面和声音 | 可视门铃、门禁机 |
| GUITION JC1060F570C | ✓ | ✓ | ✓ | ✓ | 声音 | 声音识别 |

五块板都带闹钟和倒计时。这张表和各产品的清单 `products/<产品名>/product.json` 一致。产品清单里选了哪些模块，这块板就有哪些功能。

## 固件文件怎么找

在 [Releases](https://github.com/tangeai/xiaotai-esp32/releases/latest) 的附件里，文件名是：

```text
v<版本>_<关键字>_idf<ESP-IDF 版本>_merged.bin
```

例如立创实战派 S3 的 `v0.4.0_szpi-s3_idf6.0_merged.bin`。同一块板有两个文件时，功能相同，选 `idf6.0`；只有一个文件的（GUITION 7 寸屏只有 `idf6.1`），就选那一个。

## 你的板子不在表里

想接入自己的板子，看[新板接入](../新板接入.md)。也可以到[社区](https://community.tange-ai.com/)提交型号和资料。
