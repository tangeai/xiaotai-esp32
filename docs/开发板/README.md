# 开发板

[文档地图](../README.md) · [快速开始](../快速开始.md)

小钛支持五块带触摸屏的开发板。先认准型号，再从表里点进对应的页面：页面上有这块板的 USB 口、下载模式、固件文件和它特有的功能。

## 先认准型号

- 看板子背面印的字、包装或购买记录，核对**完整型号**。只知道“ESP32-S3”或“ESP32-P4”不够，那是芯片的名字。
- 微雪 P4 的 3.5 寸和 4.3 寸是两块不同的板。这里支持的是 3.5 寸。
- M5Stack 要确认是 CoreS3-Lite。
- 两块 P4 板要求芯片版本 rev3.1 及以上。用 esptool 连接板子时，输出里会显示芯片版本。

## 每块板能做什么

下面是默认固件的功能，✓ 表示有，— 表示没有。每项怎么用，见[使用说明](../使用说明.md)。

| 功能 | 立创实战派 S3 | CoreS3-Lite | 微雪 P4 3.5 寸 | WT99P461-S1 | GUITION 7 寸 |
| --- | :-: | :-: | :-: | :-: | :-: |
| 屏幕（像素） | 320×240 | 320×240 | 480×320 | 1024×600 | 1024×600 |
| 触摸 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 屏幕亮度可调 | ✓ | — | ✓ | ✓ | ✓ |
| 摄像头 | ✓ | ✓ | ✓ | ✓ | — |
| AI 对话 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 唤醒词“你好小钛” | ✓ | ✓ | ✓ | ✓ | ✓ |
| AI 对话的声音编码 | 收 Opus、发 G.711 | 收 Opus、发 G.711 | Opus | Opus | Opus |
| 对话时让它做事 | ✓ | ✓ | ✓ | ✓ | ✓ |
| AI 看图 | ✓ | — | ✓ | ✓ | — |
| 呼叫另一台设备（语音） | ✓ | ✓ | ✓ | ✓ | ✓ |
| 微信语音通话 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 视频通话（设备之间） | 只发画面 | 只发画面 | ✓ | ✓ | 只看画面 |
| 视频通话（微信） | — | — | ✓ | ✓ | — |
| 多人对讲 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 实时查看 | 画面和声音 | 画面和声音 | 画面和声音 | 画面和声音 | 声音 |
| 声音识别 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 闹钟和倒计时 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 门禁（可视门铃、门铃室外机、门禁室内机、门禁机） | ✓ | ✓ | ✓ | ✓ | ✓ |
| 屏幕人物 | — | — | — | — | ✓ |

几项的说明：

- **声音编码**：五块板都能收 Opus（16 kHz），网络丢包时会把缺的一小段声音补上。服务端不接受 Opus 时，这一次对话结束，之后到重启前自动改用 G.711。
- **对话时让它做事**：音量、时间、闹钟、倒计时和呼叫联系人；亮度可调的板子还能调亮度。要先在控制台给 AI 角色配上设备插件，见[AI 对讲里的设备功能](../功能/AI设备功能.md)。
- **闹钟和倒计时**：各有自己的铃声，和来电铃声不同，一听就知道是哪一种。
- **视频通话**：立创 S3 和 CoreS3-Lite 没有能用的视频解码器，打给另一台设备时对方能看到它们的画面，它们自己不显示对方；GUITION 7 寸屏没有摄像头，只看对方的画面。不支持的一侧按语音接听，微信也一样。
- **门禁**：分可视门铃（一户人家：家里的可视门铃，门口的门铃室外机）和门禁（门禁室内机，拨房号的门禁机）两套，一台设备当其中一端，四种模式各是一页，左右翻，停在哪页就是哪种。WT99 开机就停在门禁，其他板在首页左右翻页就到；立创 S3 和 CoreS3-Lite 的画面只给对方看，适合放门口；GUITION 7 寸屏没有摄像头，适合当室内机看门口的画面，放门口时只有声音。见[门禁](../功能/门禁.md)。

## 固件文件怎么找

在 [Releases](https://github.com/tangeai/xiaotai-esp32/releases/latest) 的附件里，文件名是：

```text
v<版本>_<关键字>_merged.bin
```

每块板一个文件。在 Releases 页面上，每个固件附件显示的是上表“下载页上的名字”加版本号，例如「立创实战派开发板 · ESP32-S3 固件 v0.5.0」，按名字找到自己的板就行。下载到电脑上的文件名还是上面这种英文的，例如立创实战派 S3 的 `v0.5.0_lckfb-esp32s3_merged.bin`。发布的固件统一用 ESP-IDF 6.1 编译；上表“可用的 ESP-IDF”是自己编译时能选的版本。
