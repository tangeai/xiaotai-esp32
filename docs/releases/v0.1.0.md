# V0.1.0 开发版本

日期：2026-11-05。本版用于固定统一仓库的首个开发基线，后续改动继续通过新提交维护。此文记录当时的开发验证结果；多芯片分支的源码预览不提供固件，也不代表生产验收完成。

## 范围

六个产品仍在同一仓库按板独立选择源码和配置：立创实战派 S3、CoreS3-Lite、微雪 P4、WT99P461-S1、Xmini C3 V3、MZ28。保留各板原有业务、媒体、交互和专用驱动，不因版本整理删减功能。

本次把立创 S3 已验证的 TiRTC 2.6.0 / IDF 6.0.3 SDK 作为 `szpi-http` 变体接入，原通用 S3/P4/C3 库和 Xmini Mini 库不变。应用业务、媒体和 UI 源码未因这次 SDK 集成改写。

## 环境与构建

| 产品 | SDK 选择 | IDF 环境 |
| --- | --- | --- |
| 立创 S3 | `variants/szpi-http`，HTTP-only，PSRAM 兼容原子操作 | 6.0.3，固定源码内容摘要 |
| CoreS3-Lite | 原通用 S3 库 | 6.0.2，固定 Git 提交 |
| 微雪 P4 / WT99 | 原通用 P4 库 | 6.0.2，固定 Git 提交 |
| Xmini | 原独立 Mini 变体 | 6.0.2，固定 Git 提交 |
| MZ28 | 原通用 C3 库 | 6.0.2，固定 Git 提交 |

先执行 `python scripts/build.py <board> --dry-run`，核对产品、SDK 目录及 `idf_environment`；激活匹配环境后移除 `--dry-run` 构建。配置变化后按提示使用 `--fresh-config`，不混用旧输出目录。详细操作见 [架构开发指南](../架构开发指南.md)。

依赖锁保存在 `profiles/dependency-locks/`。锁内本地依赖路径按复制到 `build/<product>/firmware/dependencies.lock` 后的位置解析；不能把锁文件移到任意位置直接传给 IDF。立创 S3 的普通固件与诊断固件使用不同输出目录，诊断选项见 [本地 AT 指令](../本地诊断与AT指令.md)。

| 检查 | 本轮结果 |

| 结构、配置契约、文档相对链接、SDK 与头文件身份 | 通过 |

两份 S3 固件均使用全新生成的配置，应用版本为 `0.1.0`，APP 分区为 `0x500000`。对照此前真机试验包，诊断版有效配置只差 IDF 配置创建版本这一元数据；普通版另外关闭诊断控制台及其屏幕快照选项。运行参数和依赖版本保持一致，包括 300 ms 中断看门狗。所有构建记录中的输入和产物均重新核对，仓内对应源码与受测副本逐文件匹配。

Git 按原始字节保存 SDK 头文件、库和其他源码，不因本机自动换行设置改写校验对象。固件与原始构建证据保存在仓外，不混入源码提交。

历史证据：2026-11-03 六板默认产品完成整机构建，见 [验证状态](../VALIDATION.md) 中对应日期。2026-11-05 的 S3 隔离试验包（应用版本 `0.1.0-http-psram-test`）完成 APP-only 烧录校验、联网、AI 创建/退出和部分数字媒体收发。用户随后反馈重开会话后恢复使用；这不等于无响应问题根因已修复，也不等于本次 V0.1.0 镜像已经烧录。

## 已知问题

- AI 曾出现长时间显示聆听却没有新回复。保留现场后重开会话恢复，根因未证实，没有加入自动重启或清状态来掩盖问题。
- S3 隔离试验仍观察到 AEC 错误计数，以及相机采集/关闭超时；声学效果、相机稳定性尚未验收。
- 微信/设备双向通话、完整物理 UI/触摸、弱网和长稳等场景没有本版全量真机证据。其他五板也未因 S3 成功而标为本版实测通过。
- 六板已完成源码迁入，运行时代码仍有 `native-bound` 限制；公共端口、跨交互复用和独立新板接入证明仍待完成。
- 当前业务开关只支持已登记并检查过的默认组合，不支持任意关闭功能；新增组合须补实现、依赖、UI 和开/关回归。
- 立创 S3 APP 分区余量有限；增加功能前检查真实镜像大小，不静默删除 UI、模型或原功能。
- 立创 S3 SDK 为 HTTP-only，不提供该 SDK 路径的 HTTPS 能力；其他服务的 TLS 配置保持原样。固件数据保护及完整安全验收不在本版通过声明内。

## 后续维护

功能修正、SDK 或依赖更新形成新的提交与版本记录，不移动已有交付身份。每次问题记录包含触发条件、第一处异常、责任层和复验范围；只恢复现象时继续保留待查状态。文档、配置契约、依赖锁和对应测试一起维护。

固件、ELF、构建缓存、原始串口日志和设备备份不进入源码 Git。正式对外提供固件前，另按确定提交完成构建输入一致性检查、目标板回归和发布授权。
