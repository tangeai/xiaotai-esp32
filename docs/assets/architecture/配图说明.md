## 重新生成

图由 [Mermaid CLI](https://github.com/mermaid-js/mermaid-cli) `12.2.0` 渲染，主题在 `mermaid-config.json`。Windows 下需要 Node.js/npm、本地 Chrome 或 Chromium 系浏览器，以及微软雅黑等中文字体。

从仓库根目录运行，`BrowserPath` 指向本机实际浏览器：

```powershell
./docs/assets/architecture/render.ps1 -BrowserPath 'C:/Program Files/Google/Chrome/Application/chrome.exe'
```

脚本只更新这个目录中与 `.mmd` 同名的 PNG，不操作固件。首次运行会通过 npm 获取固定版本的渲染工具，依赖留在 npm 缓存，不写入固件组件目录。使用 headless 浏览器，不操作已有浏览器标签页。

修改图后，核对节点文字、箭头含义、当前/目标状态，并打开 PNG 检查中文、裁切和小字号。变更 `.mmd`、PNG 和对应正文图注应放在同一次文档修改中。
