## 四条常见的阅读路线

| 你是 | 建议的顺序 |
| --- | --- |
| 第一次接触，想让板子说话 | 快速开始 → 你那块板的页面 → 使用说明 |
| 只想最快看到效果 | 快速开始 → 控制台与 AI 角色 |
| 要改功能、接自己的板子 | 第一次编译 → 架构总览 → 开发指南 → 新板接入 |
| 想看设计思路 | 架构总览 → SDK 架构 → 用 AI 助手开发 |
