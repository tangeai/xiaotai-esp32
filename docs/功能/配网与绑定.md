# 配网与绑定

本页描述 SDK 产品的配网门户。手机怎么连接设备热点，见[快速开始](../快速开始.md#4-连接-wi-fi)。配网负责更新 Wi-Fi；账号绑定和 RTC 就绪要另行确认。

## 先验证，再保存

1. 在设备热点的配网页选择网络、提交凭据。收到提交成功只表示设备接下了请求。
2. 页面显示「正在验证网络」时，设备先试连选定的 Wi-Fi，连上并取得 IP 后才保存新凭据。这一步不检查云端服务是否可达。
3. 保存成功后，按设备提示等待热点关闭或重启，再看设备上的联网状态。两款 S3 保存成功后自动关闭配网页并重启一次，不需要再手动重启。

| 页面或设备提示 | 应该怎么做 |
| --- | --- |
| 找不到网络、连接超时或验证未通过 | 这次提交没有覆盖原 Wi-Fi。检查网络、信号和密码，再提交一次。 |
| 设备未能保存配置 | Wi-Fi 已通过验证，但存盘未确认成功。按设备提示重试保存，不以已连上 Wi-Fi 判定配网完成。 |
| 手机没收到保存结果就断开了热点 | 先看设备是否已经联网。确认还没连上，再接回设备热点重试。 |

测试门户时，用错密码验一次拒绝，再用正确凭据验保存与重启；已有配置的设备，还要确认验证失败后旧凭据仍可用。支持物理控制台的构建可以配合 [AT 指令](../AT指令.md) 读设备状态。

## 换网与绑定状态

- 两款 S3 的验证码重试入口在标题栏，微雪 P4 和 WT99 使用「刷新验证码」。看到环境配置错误时，先[修正测试环境](测试环境切换.md#sdk-固件怎么用)，再联网重试。
