# 测试环境切换

连接指定测试环境或自部署平台时，可以通过本地串口设置服务发现基址。普通配网不用改它。

## SDK 固件怎么用

使用开放物理控制台的构建，按[当前固件的词表](../AT指令.md#词表与权限)核对命令。立创 S3 的 SDK 默认固件不开放物理 AT。

1. 空闲时执行 `AT+EP`。先记下 `active`（本次启动入口）、`saved`（保存的覆盖值）和 `next`（下次启动入口）。`saved=default` 表示没有覆盖项，`?` 表示保存值还未确认。
2. 确认目标环境和操作权限后，用 `AT+EP SET http://test.example.com:8080/pre` 提交基址，或用 `AT+EP RESET` 恢复默认入口。不带 `/services`。`OK` 表示受理，不表示改动已经保存；忙线、配网正在处理或维护资源不足时，按命令返回的错误处理。
3. 保存成功会发出 `+EP: result=saved error=0` 并重启。重启后再查 `AT+EP` 和平台在线状态。等待中的请求可用 `AT+EP CANCEL`；开始保存后不再受理取消。失败后先看 `error` 和保存值，不把未确认的写入当成回滚。

正在进行的通话或已接纳的实时查看不会被切换命令踢掉。反过来，设备进入环境维护后会挡住新的实时查看，取消后恢复。切换只改服务发现入口，不清 Wi-Fi、设备身份或绑定；目标平台仍须接受现有身份。
