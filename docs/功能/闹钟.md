# 闹钟

闹钟由两部分组成：`clock` 模块保存闹钟和倒计时、到点发出 `clock.due`（前面还有一个同样内容的 `clock.fired`，后台的应用也收得到）；`alarm` 应用负责屏幕上的时钟页、闹钟、倒计时、设置、响铃和停止。产品清单的 `applications` 里写上 `alarm`、`modules` 里写上 `clock` 就有这些功能。五款彩屏产品（立创实战派 S3、CoreS3、GUITION 7 寸屏、微雪 P4、WT99）都选上了，从首页翻页就能到闹钟的时钟页。产品同时带 `ai_talk` 时，还可以在 AI 对讲里用说的设闹钟和倒计时，见 [AI 对讲里的设备功能](AI设备功能.md)。

## 页面

| 页面 | 内容 | 操作 |
| --- | --- | --- |
| 时钟页（`alarm.home`） | 大字时间、日期；下面一行是下一个闹钟，有倒计时在走时显示还剩多久 | 底部「闹钟」「倒计时」「设置」；左右滑动或点两侧箭头翻页。在这一页说唤醒词，时钟不切走：卡片的位置换成一排跟着声音动的小条、对话状态和字幕，底部换成「音量」「结束」，说完恢复原样 |
| 闹钟列表（`alarm.list`） | 每个闹钟一行：时间、重复方式、开或关 | 点一行修改，「添加闹钟」新建，「返回」回时钟页 |
| 设闹钟（`alarm.edit`） | 时、分、重复（仅一次、每天、工作日、周末）、开启 | 「保存」「取消」；修改已有闹钟时多一个「删除」 |
| 倒计时（`alarm.timer`） | 没在走时选时长（1–180 分钟）；在走时显示还剩多久，每秒更新 | 「开始」或「取消倒计时」 |
| 闹钟设置（`alarm.settings`） | 响铃时长（30 秒、1、2、5 分钟）、稍后提醒间隔（5、10、15 分钟）、时区 | 选了就生效，重启后还在 |
| 响铃（`alarm.ringing`） | 大字时间和这次到点的闹钟 | 「停止」或「稍后提醒」 |

时区一项只在产品打开 `parameters.clock.timezone_setting` 时出现，可选北京时间、东京、迪拜、柏林、伦敦、纽约、洛杉矶、悉尼；夏令时按各地规则自动切换。

## 响铃

- 到点时设备空闲，就点亮屏幕、切到响铃页、循环播放铃声，直到点「停止」，或者到了响铃时长自动停止。停止后回到响铃前的页面。
- 闹钟和倒计时各有自己的铃声：闹钟是双铃闹钟的「叮铃铃」，倒计时是四声短促的提示音。
- 点「稍后提醒」，铃声停止，过设置的间隔再响一次，响铃页仍显示原来那个闹钟的时间。
- 正在通话、AI 对讲、多人对讲或实时查看时到点，不打断当前会话，等会话结束约 1.5 秒后补响，响铃页写明「刚才到点」或「几分钟前到点」。会话期间到点的有好几个，就按到点先后一个接一个响，每个单独停止或稍后提醒。超过一小时还没机会响的不再补；期间被删掉的闹钟、被关掉的重复闹钟也不补。重启后不补。
- 响铃时有来电、开始 AI 对讲或声音识别，铃声立即停止，屏幕交给它们；没有人点「停止」或「稍后提醒」的，等它们结束再响一次。实时查看和多人对讲不打断响铃，要等铃声停了才能开始。
- 倒计时到点按同样的方式响铃。
- 时间还没同步时闹钟不会响，时钟页会提示「时间同步后闹钟才会响」。

闹钟和设置保存在设备上，重启后还在；倒计时不保存。

## 产品参数

| 键名 | 缺省 | 说明 |
| --- | --- | --- |
| `parameters.alarm.ring_s` | `60` | 响铃时长的出厂值，可选 30、60、120、300 秒；用户在设置页改的值优先 |
| `parameters.alarm.snooze_min` | `5` | 稍后提醒间隔的出厂值，可选 5、10、15 分钟 |
| `parameters.alarm.minute_step` | `5` | 设闹钟页「分」每点一下变化的分钟数，1–30 |
| `parameters.clock.timezone_setting` | `false` | 设置页出现「时区」 |
| `parameters.companion.clock_home_off` | `false` | 去掉 companion 自己的时钟页，让翻页后的第一页就是闹钟页 |
| `priorities.alarm` | `1` | 响铃这项活动的优先级；其他会话的优先级更高时可以打断它 |

用户设置存在 `alarm.ring_s`（键 `alarm_ring`）、`alarm.snooze_min`（键 `alarm_snooze`）和 `clock.timezone`（键 `clock_tz`）。

## 铃声

两种铃声由 `alarm` 应用自己带，8 kHz 单声道，名字是 `ring.alarm` 和 `ring.timer`，由 `scripts/generate_alarm_sounds.py` 合成，数据在 `apps/xiaotai_app_alarm/src/alarm_sounds_data.inc`，固件里约 19 KB。改完合成的参数后重新运行脚本就会写回这个文件；加 `--wav <目录>` 同时写出 WAV 文件，方便试听。

产品要换成自己的声音，登记一个同名的声音，就会替换自带的这一个。

## 指令

| 指令 | 作用 |
| --- | --- |
| `AT+ALARM` | 读应用状态：所在页面、是否在响、响铃、停止、稍后提醒、超时次数，以及等着补响（`pending`）、补响过（`late`）、放弃补响（`dropped`）的个数 |
| `AT+CLOCK` | 读当前时间和所有闹钟、倒计时 |
| `AT+CLOCK ALARM <hh:mm> <0..127> [<label-hex>]` | 加一个闹钟；第二个参数是星期位，0 表示只响一次 |
| `AT+CLOCK COUNTDOWN <seconds> [<label-hex>]` | 加一个倒计时 |
| `AT+CLOCK REMOVE <id>`、`AT+CLOCK ENABLE <id> <0\|1>` | 删除、开关闹钟 |

调试时可以用 `AT+CLOCK COUNTDOWN 5` 触发一次响铃，`AT+UI TAP <x> <y>` 点「停止」或「稍后提醒」。指令的授权等级见 [AT 指令](../AT指令.md#词表与权限)。
