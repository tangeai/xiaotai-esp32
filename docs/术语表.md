# 术语表

[文档地图](README.md) · [快速开始](快速开始.md) · [常见问题](常见问题.md)

文档里反复出现的词，按“先遇到的先解释”排列。每个词只有一个意思，全套文档都按这里的用法写。

## 上手时会遇到的

| 词 | 意思 |
| --- | --- |
| 固件 | 装在开发板里的程序。小钛就是一份固件 |
| 烧录 | 把固件写进开发板 |
| 完整镜像 | 一个文件就包含启动程序、分区表和应用的固件，文件名以 `_merged.bin` 结尾，从地址 `0x0` 写入 |
| 下载模式 | 芯片等待电脑写入固件的状态。多数板子连上 USB 后由工具自动进入，少数要按键 |
| 配网 | 告诉设备连哪个 Wi-Fi、密码是什么 |
| 热点 | 配网时设备自己发出的临时 Wi-Fi，名字是 `XiaoTai-` 加四位后缀 |
| 绑定 | 把设备加进你的账号，之后才能在手机和网页上找到它 |
| 验证码 | 绑定时设备屏幕上显示的六位数字，有倒计时，过期会换新的 |
| 小钛控制台 | 网页 `https://xiaotai.chat/devices`，登录后管理设备、换 AI 角色、发起实时查看 |
| 小钛小程序 | 微信里的“小钛”小程序，功能和控制台相近，另外负责微信通话的授权和接听 |

## 功能的名字

| 词 | 意思 |
| --- | --- |
| AI 对话 | 对设备说话，AI 用语音回答。代码里的模块名是 `ai_talk` |
| AI 角色 | AI 的人设、音色和能力，在控制台里选择或自己写 |
| 设备对讲 | 一台设备呼叫另一台设备，接听后双向通话 |
| 微信通话 | 设备和手机微信之间的语音或视频通话 |
| 多人对讲 | 几台设备进同一个房间，按住说话，其他人都能听到 |
| 实时查看 | 在控制台或小程序里看设备摄像头的画面、听声音、对设备说话 |
| 唤醒词 | 让设备开始听你说话的那句话，小钛的唤醒词是“你好小钛” |

## 开发时会遇到的

| 词 | 意思 |
| --- | --- |
| ESP-IDF | 乐鑫官方的开发框架，编译 ESP32 程序要用它 |
| TiRTC | 小钛使用的实时音视频库和服务。库以官方发布包的形式在编译时下载，不在仓库里 |
| 板包 | `boards/<厂商>/<板>/` 目录，写清一块板有什么硬件、怎么接线 |
| 产品清单 | `products/<产品名>/product.json`，写清一款产品选哪块板、带哪些功能 |
| 应用 | `apps/` 下的组件，组织页面流程和交互，例如伴侣应用、门禁应用、闹钟应用 |
| 基础模块 | `sdk/modules/` 下的组件，提供一项可复用的业务，例如通话、配网、绑定 |
| 引擎 | `sdk/xiaotai_*` 下的组件，提供底层能力，例如媒体、传输、界面 |
| 零件 | `sdk/parts/` 下的芯片驱动，例如某款屏、某款音频芯片 |
| 选型器 | `scripts/sdk_selection.py`，按产品清单挑出组件，并核对板子有没有它们需要的硬件 |
| 变体 | 产品清单里预先声明的另一种功能组合，编译时用 `--variant` 选择 |
| 意图 | 一个“想做某事”的请求，例如 `talk.start`。按键、触摸、串口指令发出意图，由负责的模块处理 |
| 事件 | 一件“已经发生”的事，例如 `wake.detected`。模块发出事件，关心的组件订阅 |
| 前台活动 | 同一时间占用麦克风和喇叭的那件事，例如通话或 AI 对话。框架按优先级决定谁先 |
| 代次 | 每次会话的编号。迟到的旧消息编号对不上，直接丢弃 |
| AT 指令 | 通过 USB 串口发给设备的文本命令，用来查状态和触发动作 |
| 主机测试 | 不用开发板，在 Linux 电脑上编译并运行同一套业务代码的测试 |
| 技能 | 仓库里写给 AI 编程助手的操作手册，放在 `.claude/skills/` |
| 分区表 | Flash 里各块区域的划分。其中 `nvs` 分区存着配网和绑定信息 |
| PSRAM | 开发板上外挂的大容量内存，文档里也叫“外部内存” |
