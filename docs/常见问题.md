# 常见问题

[文档地图](README.md) · [快速开始](快速开始.md) · [使用说明](使用说明.md) · [术语表](术语表.md)

按“卡在哪一步”分组。每条先说该检查什么，再说原因。

## 开始之前

**没有开发板，能先试试吗？**
能。官网提供在电脑上运行的设备模拟器，可以走一遍绑定和音视频流程，见 [xiaotai.chat 的入门页](https://xiaotai.chat/getting-started)。模拟器播放的是文件里的音视频，不涉及真实的麦克风、喇叭和摄像头。

**我的板子也是 ESP32-S3，能直接用吗？**
不一定。同一种芯片的板子，屏幕、音频芯片、引脚和内存配置都可能不同。固件按完整型号区分，型号在[开发板列表](开发板/README.md)里才能直接用；不在的要先[接入](新板接入.md)。

**固件依赖哪些服务？能自己部署吗？**
固件本身开源，按 MIT 许可使用。AI 对话、通话和实时查看要连接小钛的云端服务；想自己部署，见 [tangeai/tirtc-server-example](https://github.com/tangeai/tirtc-server-example)。

**要自己准备 AI 的密钥吗？**
不用。AI 对话由小钛的云端服务提供，绑定之后就能用；想换性格和声音，到[小钛控制台](https://xiaotai.chat/devices)里选 AI 角色，做法见[控制台与 AI 角色](控制台与AI角色.md)。

## 烧录

**为什么一定要用 Chrome 或 Edge？**
网页烧录靠浏览器直接连接串口，这个功能目前只有 Chrome、Edge 这类浏览器有，Safari 和 Firefox 没有。

**电脑里找不到开发板的串口。**
串口是电脑和开发板通信的通道。按顺序排查：

1. 换一根确认能传文件的 USB 线。只能充电的线不行。
2. 对照这块板的页面，确认插的是指定的那个口。
3. 关掉其他连着这块板的烧录网页或串口软件，拔掉 USB 线再插回去。
4. 用的是 Windows 电脑，板子是微雪 P4 或 WT99 的，看下一条装驱动。

**Windows 上插了板子，设备管理器里显示未知设备。**
板子是微雪 P4 或 WT99 的话，到芯片厂商的[驱动下载页](https://www.wch.cn/downloads/CH343SER_EXE.html)装 CH343 驱动，装完重新插一次 USB 线。原因是这两块板通过板上的 USB 转串口芯片（CH343）连接电脑，个别电脑没有自带它的驱动。另外三块板走芯片原生 USB，不需要装驱动。

**烧录工具连接不上开发板。**
按这块板的页面上的方法让板子进入下载模式，再连一次。每块板的按键不一样，见[开发板](开发板/README.md)里各自的页面。

**该选 `idf6.0` 还是 `idf5.5` 的文件？**
选 `idf6.0`。两个文件功能相同，区别只在编译它们的 ESP-IDF 版本，这对只是使用的人没有影响。

**烧录后黑屏，或者不停重启。**
先核对固件关键字和板子的完整型号是否一致，再重新下载文件烧一次。型号一致仍然如此，带上板子型号和固件版本来反馈。

**重新烧录后，原来的 Wi-Fi 和绑定没有了。**
完整镜像（`_merged.bin`）从头写入，会覆盖这些信息，重新配网和绑定即可。开发时想保留它们，可以只更新应用部分，见[第一次编译](第一次编译.md#只更新应用保留配网和绑定)。

## 配网

**手机找不到 `XiaoTai-XXXX` 热点。**
确认设备停在「连接 Wi-Fi」页。手机靠近设备，刷新 Wi-Fi 列表。

**连上热点后手机提示“无互联网连接”。**
这是正常的。此时手机连的是设备，不是路由器。保持连接，继续打开配网页。

**打不开配网页。**
确认手机此刻连着设备的热点，在浏览器里输入 `http://192.168.6.1`。注意开头是 `http`，不是 `https`。

**家里的 Wi-Fi 把 2.4G 和 5G 合成了一个名字，能用吗？**
能。设备会连到其中的 2.4 GHz。

**手机热点、公司或学校的网络能用吗？**
手机热点可以，注意把热点的频段设成 2.4 GHz。连上后还要打开网页登录的网络（酒店、校园网）用不了，设备没法替你完成网页登录。

**提交后提示密码错误或连接失败。**
设备会先试连，连上才保存，所以这次失败不会影响原来的设置。核对 Wi-Fi 名称和密码，确认是 2.4 GHz 的网络，再提交一次。

**想换一个 Wi-Fi。**
在设备上点右上角的「···」打开菜单，进「设置 → 网络信息 → 断开当前连接」。设备回到「连接 Wi-Fi」页并重新发出热点，再按[快速开始](快速开始.md#3-配网)配一次网。换网络不影响绑定。

## 绑定

**能在电脑上绑定吗？**
能。[小钛控制台](https://xiaotai.chat/devices)是网页，电脑和手机的浏览器都可以打开。在电脑上绑定，手机就不用来回切换网络。

**输入验证码后没有反应。**
手机要先从设备热点切回能上网的网络。验证码有倒计时，过期后用屏幕上的新码。

**设备列表里有这台设备，但显示离线。**
列表不会自动刷新，先点一下“刷新”。仍然离线，看设备屏幕右上角的 Wi-Fi 图标：

- 图标是灰的：设备没连上 Wi-Fi。检查路由器，或者按上面“想换一个 Wi-Fi”重新配网。
- 图标正常：把设备重启一次，再刷新列表。

**屏幕一直显示「设备尚未就绪」。**
设备还在连接网络或服务，稍等片刻。长时间不变就重启一次。

## 使用

**说“你好小钛”没有反应。**
看首页左上角是不是「待唤醒」，再看「设置」里麦克风是否开着。也可以直接点屏幕中间的表情开始。

**AI 听到了，但一直不回答。**
确认设备在线。记下发生的时间和当时屏幕上的状态，方便反馈时定位。

**声音太大或太小。**
在设备上点右上角的「···」打开菜单，进「设置」，用「−」「+」调音量。

**打不通另一台设备。**
对方在通讯录里要显示“在线”。两台设备要联网，并且绑定在同一个账号下。

**通话中对方听不到我。**
看是不是点过「关闭麦克风」。两台设备放在同一个房间里通话，声音会互相干扰，分开放再试。

**微信呼叫不了设备。**
微信通话要先在“小钛”小程序里给设备授权。授权前小程序会要求先给设备起一个名字。

## 开发

只是下载固件来用的话，这一节可以跳过。遇到开不了机或通话不正常，先看上面的“烧录”“使用”两节。

自己改代码之后遇到编译报错、开不了机、通话异常或内存不足，按[测试与诊断](测试与诊断.md)的方法定位。用 AI 编程助手时，直接描述现象，它会按仓库里的排查手册 `xiaotai-verify` 一步步检查，见[用 AI 助手开发](用AI助手开发.md)。

## 反馈问题时请提供

板子的完整型号、固件版本（下载的固件文件名开头，例如 `v0.4.0`）、卡在哪一步、屏幕上显示了什么、发生的时间。有截图可以一起发。

> **注意**：发截图或日志之前，先遮住验证码、Wi-Fi 密码和设备密钥。

可以在 [GitHub Issues](https://github.com/tangeai/xiaotai-esp32/issues) 或[社区](https://community.tange-ai.com/)里提出。
