# Expressions

The expressions are drawn by code of this project (`src/lcd_face*.c`, MIT).
No pictures, fonts or other files go with them.

Their general look follows the earlier procedural expressions of the XiaoTai
project, which the project owner confirmed for internal use and public
distribution with the XiaoTai SDK and firmware (poses, colors and motion
tracks; not unrelated images, fonts, or marks). The files of that earlier
model, Git commit `3140fcfea002e3481809646bcf43d83b46b37898` of the XiaoTai
development repository, SHA-256
`f97dfc6218f2cb5a337c9386e507ec62d69fe8cbee0b85ea106b4ff2bc1eb829`, are not
part of this tree.
