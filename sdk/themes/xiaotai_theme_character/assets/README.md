# 人物贴图包

`character.pack` 是屏幕人物的全部画面素材，也是“她是谁”的全部定义：画面本身、各部位在画面里的位置、她有哪些部件和姿势。固件代码里不写任何一个角色的尺寸和部位，换一个包就是换一个人物。图按行程编码存放，整身图各带一个 256 色调色板（一个像素一个字节）；包头和每张图都有校验和。包接在应用镜像后面、留在 Flash 里，设备按需读（见[屏幕人物](../../../../docs/功能/屏幕人物.md#素材包在哪)）。

## 现在这位：小钛

钛银渐变到天蓝的长发、齐刘海、右侧一条小辫和六边形发夹、水蓝色眼睛，白色连帽裙配海军蓝水手领和天蓝色蝴蝶结。

她是项目自己做的原创形象，用图像生成模型出图（2026-11-24），不含第三方美术素材。脸上的差分图都从同一张底图改出来，除了被改的那一处，其余逐像素一致，所以能直接切成贴片；姿势图是另外生成、再和底图对齐的。

设备怎么用它们：平时画底图，眼、嘴、眉按表情盖上对应的贴片，换表情时各自淡变过去；她整个人一起动，画面不拆开也不扭曲：以脚下为定点变高变矮来呼吸，左右、上下都只有几个像素；问好、托腮这类动作换成整张姿势图，换的时候慢眨一次眼、在闭着眼时换，不叠化也不下蹲。一个姿势也可以由几张图连着播（配方里的 `clips`）：进入和离开先过一张过渡图，小舞是十六拍一循环、每拍直接切一张，点头是“半低、低头、半低、底图”走两遍，赌气、睡着是两张来回切。问好那张是轻抬手掌的图换上半开的笑眼（配方里姿势的 `face`：把从底图改出来的眼睛按差分盖到一张脸和底图对齐的姿势图上）。特效图按种类放（每种最多 12 帧），播帧的那几种在一颗粒子的寿命里从头播到尾，其余的是同一样东西的几个样子。

原来的看左看右、睁大、看上、大张嘴、鼓脸和哭的整脸、叉腰挥手和它的三张、双手举过头的欢呼和它的两张、大笑的三张、侧耳听、比心、吓一跳和八张大舞不再放进包里（原图都还在）。

## 重新生成

原图不在仓库里，按配方里的路径放在一个目录下（`anchor/`、`parts/`、`gen5/`、`norm/`、`fx/`）：脸的差分图和姿势图每张 1024×1536，差分图是纯绿底，姿势图已经抠好、带透明通道；特效图按显示的大小画好、带透明通道，几帧的就是一行等宽的格子（配方里写帧数和放大多少）。

```
python tools/character/bake.py --pictures <原图目录>
```

配方是 `tools/character/recipes/xiaotai.json`：写明每张图是什么、眼和嘴的方框在画布上的位置、眼睛和下巴等几个标记点。出新图时要守住的规矩：每张差分都从底图改，只改一处；背景保持纯绿；人物身上不要有绿色。

## 换一个人物

两种做法，烘出来的包固件都认：

- **平图**（现在用的）：一张底图，加上从它改出来的眼嘴差分图和几张姿势图。复制 `xiaotai.json`，改掉图的路径、方框和标记点。
- **分层人偶**：用带骨骼的 Inochi2D 人偶，按它自己的参数摆出每一档眼睛、口型、手臂和转头，切成分层小图。例子是 `tools/character/recipes/aka-midori.json`（两个 CC BY 4.0 的示例人偶拼成一个角色；这个例子的包没有随固件发布，用它烘焙并发布时要按配方里写的出处署名）。

包里带不带兽耳、尾巴、手臂、转头、姿势图，固件开机时自己认出来，没有的部件对应的动作就不做。
