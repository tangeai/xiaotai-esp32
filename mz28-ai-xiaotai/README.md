# 小钛 MZ28

小钛 MZ28 是 MZ28-AI-PPD V1.2 上的无屏语音应用，版本为 **1.0.0**。基于 **TiRTC/WebRTC** 提供实时双向 Opus 语音，支持 Wi-Fi 热点配网、六位码语音绑定、微信语音通话、BOOT 操作和七颗 RGB 灯反馈，使用正式版“小钛”小程序。

## 先体验

下载 [1.0.0 完整 8 MB 烧录包](https://github.com/tangeai/xiaotai-esp32/releases/download/mz28-ai-app-v1.0.0/xiaotai-mz28-1.0.0-full-8MB.bin)，按[网页烧录说明](#用浏览器烧录)从 `0x0` 写入，无需安装 ESP-IDF。完整包为 **8,388,608 字节，会清除配网、身份和用户设置**，不能用于 S3/P4。

[发布页](https://github.com/tangeai/xiaotai-esp32/releases/tag/mz28-ai-app-v1.0.0)同时提供烧录说明、SHA-256 清单和构建记录；可选固件 ZIP 含同一次构建的 APP 和启动分段，供已确认相同分区的保留配置升级使用。`Source code` 是源码，不是固件。

## 用浏览器烧录

1. 用 USB 数据线连接 MZ28，关闭占用串口的终端，在 Chrome/Edge 打开[乐鑫在线烧录工具](https://espressif.github.io/esptool-js/)。
2. 点击 **Connect**，选择 MZ28 串口并确认 ESP32-C3。连接不上时，按住 BOOT、点按 RESET，再松开 BOOT。
3. 添加完整 `full-8MB.bin`，地址填 **`0x0`**，Flash 参数选 `keep`，点击 **Program**，等待校验完成后复位。无需额外整片擦除。

镜像参数为 DIO / 80 MHz / 8 MB，支持 C3 rev 0.3–1.99。首次配网、绑定与按键操作见下文；保留配置升级和命令行方式见[详细烧录说明](docs/FLASHING.md)。

## 准备什么

| 项目 | 要求 |
| --- | --- |
| 设备 | MZ28-AI-PPD V1.2，ESP32-C3、8 MB Flash、VB6824、麦克风和扬声器 |
| 供电 | USB-C 稳定供电；烧录时使用可传输数据的 USB 线 |
| 联网 | 可访问平台的 2.4 GHz Wi-Fi |
| 体验条件 | [体验平台](https://xiaotai.chat/)账号、手机和正式版“小钛”微信小程序 |

已有固件包即可先使用，不必安装 ESP-IDF。二次开发使用 ESP-IDF **5.5.5**、RISC-V GCC **14.2.0** 和随工程提供的 TiRTC **2.5.0**。

## 开始使用

1. 新设备按[烧录说明](docs/FLASHING.md)安装对应固件。**完整 8 MB 镜像会清除本机配网和身份；相同分区保留配置升级只写 APP。**
2. 上电后，按语音提示在手机 Wi-Fi 设置连接 `XiaoTai-XXXX`，打开 [192.168.6.1](http://192.168.6.1)，选择附近的 2.4 GHz 网络并输入密码。
3. 联网后听取六位验证码，在[体验平台](https://xiaotai.chat/)添加设备并填写验证码；绑定完成后，在正式版“小钛”微信小程序中完成通话授权。
4. 在线待机时单击 BOOT 呼叫第一位微信联系人；来电时单击接听，双击拒接；拨号或通话中双击挂断。

完整本机操作见[使用说明书](docs/USER_GUIDE.md)，包括重新配网、清除本机身份、灯光、铃声和常见问题。

## 使用范围

- 微信语音支持设备呼手机、手机呼设备，以及双方取消、拒接和挂断。
- 设备使用真实麦克风和扬声器进行双向 Opus 语音；没有屏幕，不使用屏幕菜单或扫码按钮。
- 未保存 Wi-Fi 时进入热点配网；更换网络连按四下 BOOT，不清除绑定身份。
- 联网待绑定时循环播报六位验证码；长按 BOOT 7 秒清本机身份、保留 Wi-Fi，不等于云端账号解绑。
- 联系人由平台授权和同步，设备单击默认呼叫当前列表的第一位。

当前版本不提供 AI 对话、设备间呼叫、多人对讲、H5 查看、摄像头或 OTA。开放热点仅用于近距离配网，NVS 默认未加密；部署前评估凭据存储和网络安全。
