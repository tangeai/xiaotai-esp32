# 更新记录

## 1.0.0

- 首次公开 MZ28-AI-PPD V1.2 无屏应用，基于 TiRTC/WebRTC 提供微信双向实时语音，使用 Opus 16 kHz / 20 ms 和正式版“小钛”小程序。
- 支持热点配网、六位码语音绑定、BOOT 呼叫/接听/拒接/挂断、七颗 RGB 灯及通话提示音。
- 提供完整 8 MB 镜像、同版分段固件和本机使用说明。

## 0.1.0 预发布候选

- 适配 MZ28 无屏 ESP32-C3、VB6824 实时语音和七颗 RGB 指示灯。
- 使用 Wi-Fi 热点配网，联网验证成功后保存并重启，不依赖蓝牙。
- 配网时播报 Wi-Fi 操作提示，联网待绑定时循环播报六位验证码。
- 支持正式版微信小程序双向 Opus 通话、来电铃声、拨号回铃和结束提示。
- 支持单击呼叫/接听、双击拒接/挂断、四连击重新配网、长按七秒清除本机身份。
- 本机使用说明与开发、移植、验收文档分开，明确平台验证码绑定和微信通话授权的操作顺序。
