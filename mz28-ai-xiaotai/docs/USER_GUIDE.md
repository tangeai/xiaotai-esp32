# 小钛 MZ28 使用说明书

本说明适用于已安装 1.0.0 固件的 MZ28-AI-PPD V1.2。设备没有屏幕，通过语音、七颗 RGB 灯和 BOOT 按键操作。首次安装固件见[烧录说明](FLASHING.md)。

## 准备什么

| 项目 | 要求 |
| --- | --- |
| 供电 | USB-C 稳定供电 |
| 网络 | 可访问互联网的 2.4 GHz Wi-Fi |
| 体验条件 | [体验平台](https://xiaotai.chat/)账号、手机、正式版“小钛”微信小程序及通话权限 |
| 按键 | BOOT 负责呼叫和设置，RESET/RST 负责重启 |

## 首次配网与绑定

### 1. 连接设备热点

1. 上电。没有已保存 Wi-Fi 时，设备进入蓝色配网灯效，播报“请打开WiFi来为设备配置无线网络。”
2. 在手机的 **Wi-Fi 设置** 连接开放热点 `XiaoTai-XXXX`，无需密码。不同设备的热点后四位不同。
3. 手机提示“无法上网”时选择保持连接。未自动打开配网页时，用浏览器访问 [http://192.168.6.1](http://192.168.6.1)。此步骤不在微信小程序中操作。
4. 等待附近网络列表，点选目标 Wi-Fi，输入密码后点“保存并连接”；隐藏网络从“其他网络”手动输入。需要时刷新扫描。
5. 等待设备验证网络。**提交成功不等于已经联网**；设备获得 IP 后才保存并自动重启，热点随之关闭。此时将手机切回可上网的网络。

**预期结果：**设备联网；未绑定时开始播报六位验证码，已绑定时恢复在线待机。

密码错误时，热点继续保留，等待本次验证结束后重新输入。路由器一直无法分配 IP 时，先检查路由器，必要时重启设备后重试。配网只使用 Wi-Fi，不需要蓝牙。

### 2. 填写六位验证码

1. 听取设备循环播报的六位数字，开头的零也要填写。
2. 手机切回可上网的网络，登录[小钛体验平台](https://xiaotai.chat/)，打开设备页面，添加设备并填写这六位验证码。
3. 按平台提示完成配置，等待设备在线。

当前固件的语音提示会提到微信小程序；其中播报的六位数字用于上述体验平台绑定，微信通话授权在下一步单独完成。

**预期结果：**验证码播报停止，设备进入在线待机。绑定成功后断电重启，不必重新填写验证码。

### 3. 授权微信通话

在微信搜索并打开正式版“小钛”小程序，在“我的设备”中选择该设备，按页面提示完成“授权呼入”，并允许手机麦克风等必要权限。本机没有屏幕或二维码，不需要在设备上寻找扫码入口。

**预期结果：**设备获得微信授权联系人，可呼叫或接听。六位码绑定与微信通话授权是两步；设备已在线，不代表已有通话联系人。

## 微信通话

### 设备呼手机

1. 等待青绿色待机灯效，单击 BOOT 后松开。
2. 设备呼叫当前第一位微信联系人，播放滴滴拨号回铃。
3. 手机接听后，回铃停止，设备进入绿色通话灯效，可以双向说话。
4. 未接通时双击 BOOT 取消；通话中双击 BOOT 挂断。手机端也可以结束。

第一位联系人以平台当前返回顺序为准。没有授权联系人、未联网或尚未就绪时，单击不会成功拨号。通话中单击不是挂断操作。

### 手机呼设备

1. 在正式版“小钛”中选择在线设备，发起语音通话。
2. 设备响铃、绿色灯交替闪烁时，单击 BOOT 接听，或双击 BOOT 拒接。
3. 通话中双击 BOOT 挂断，或在手机上结束。

**预期结果：**双方可以持续听见对方；结束后停止铃声和通话音频，恢复待机，可以再次呼叫。手机在接听前取消，设备也应停止响铃。

## 按键与重新设置

| 操作 | 场景 | 结果 |
| --- | --- | --- |
| 单击 BOOT | 在线待机 | 呼叫第一位微信联系人 |
| 单击 BOOT | 来电振铃 | 接听 |
| 双击 BOOT | 来电振铃 | 拒接 |
| 双击 BOOT | 拨号、连接、等待接听或通话 | 取消/挂断 |
| 连按四下 BOOT | 更换 Wi-Fi | 清除已保存 Wi-Fi，重启进入配网；保留绑定身份 |
| 持续按住 BOOT 7 秒 | 重新绑定设备 | 清除本机身份并重启；保留 Wi-Fi |
| 点按 RESET/RST | 需要重启 | 重新启动，保留已保存的数据 |

连续点击的相邻间隔保持在约 350 ms 内。四连击在第四次松开后执行，**不是长按四秒**；三连击没有功能。正常使用先松开 BOOT 再操作，不要一直按着 BOOT 上电。

重新配网后仍使用原绑定关系。长按七秒只清本机身份，**不会代替云端账号解绑**；账号解绑在平台或小程序的设备管理入口操作。完整镜像会清除本机数据，不用重新烧录代替日常设置。

## 灯光与声音

| 状态 | 灯光 | 声音或含义 |
| --- | --- | --- |
| 开机 | 青蓝跑马 | 正在初始化 |
| Wi-Fi 配网 | 蓝色呼吸、白色单灯移动 | 提醒打开 Wi-Fi 配网 |
| 等待绑定 | 暖橙呼吸 | 循环播报绑定提示和六位验证码 |
| 网络连接中 | 蓝色跑马 | 正在连接网络和平台 |
| 在线待机 | 低亮青绿色呼吸 | 可以发起或接听通话 |
| 呼出 | 快速青蓝跑马 | 滴滴拨号回铃 |
| 来电 | 绿色奇偶灯交替 | 来电铃声 |
| 建连中 | 黄蓝跑马 | 等待通话接通 |
| 通话中 | 绿色呼吸、中间灯提亮 | 已进入双向语音 |
| 挂断中 | 红色短脉冲 | 正常结束音；异常结束使用警告音 |
| 启动失败 | 红色双闪 | 检查网络和供电 |

按键反馈会短暂覆盖状态灯效，通话中不插播普通点击音。配网提示在进入配网时播放；六位绑定码在待绑定期间循环播报。

## 遇到问题

| 现象 | 先检查 |
| --- | --- |
| 找不到设备热点 | 确认供电；需要重新配网时四连击 BOOT，等待重启后搜索 `XiaoTai-XXXX` |
| 热点能连，配网页打不开 | 保持热点连接，输入完整 `http://192.168.6.1`；暂时关闭自动网络切换或 VPN |
| 附近没有目标网络 | 刷新并等待扫描；确认路由器提供 2.4 GHz，隐藏网络手动输入 |
| 提交密码后没有重启 | 核对密码和路由器；等待验证结束后重试，勿连续提交 |
| 没有播报验证码 | 已绑定设备通常不再播报；未绑定设备先确认 Wi-Fi 可以上网 |
| 验证码不能绑定 | 在体验平台填写当前正在播报的完整六位码，保留开头的零；确认手机可以上网 |
| 待机单击没有拨号 | 确认已完成微信通话授权、存在联系人，并等待设备在线 |
| 设备响铃但接不起来 | 确认操作 BOOT 而不是 RESET；单击接听，双击是拒接 |
| 一侧听不到声音 | 检查手机麦克风权限、是否静音、设备扬声器及网络，结束后重新呼叫 |
| 断续、回声或失真 | 检查稳定供电和 Wi-Fi，分开摆放手机与设备，避免扬声器紧贴麦克风 |

需要反馈时，提供板型、固件版本、操作步骤和发生阶段；不要公开验证码、Wi-Fi 密码或账号身份信息。开发检查与验收方法另见[测试与验证](TESTING.md)。
