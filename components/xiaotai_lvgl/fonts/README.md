# 彩屏中文字库

原生应用和 SDK 彩屏主题共用这两份 C 位图，构建时不下载、不生成字体。主字库和补充字库保留原符号名、18 px、20 px 行高、3 px 基线以及 2/4 bpp。汉字和全角符号保留原来的 18 px 字宽，布局不变；ASCII 字母、数字和标点用思源黑体自己的比例字宽，英文和数字不再有多余空隙。绘制时 Noto 的少量过宽或越界笔画会按整字缩放或移动，不裁掉笔画。

主字库用仓内 Noto Sans SC Medium 500，只排除原字库中的 `U+2252`（钉住的 Noto 源不含此字形）。补充字库继续覆盖原 131 个码位，其中 97 个来自同一 Noto 源，另外 34 个沿用原位图及字形度量。补充文件首注释和 [`font_source.json`](font_source.json) 登记了这 34 个码位、旧文件哈希和来源。OFL 只适用于 Noto 生成的部分，原位图授权不变，详见 [第三方来源与许可](../../../THIRD_PARTY.md)。

在仓库根目录执行 `python -B scripts/generate_lcd_fonts.py --check`，核对源哈希、覆盖范围、位图索引、边界和原样保留的位图；装有 Pillow（含 FreeType）与 fontTools 的本地环境可用 `--write` 重生成。工具版本和生成文件哈希均在清单里。普通编译不依赖 Python 字体工具。
