# H5 双向语音

CoreS3-SE 没有摄像头，实时查看只提供双向音频。页面入口仍沿用平台的“实时查看”，
不要求视频画面，也不初始化摄像头。首次操作见[开发指南](GETTING_STARTED_CN.md#h5-查看与对讲)。

## 音频契约

方向以设备为准：

| 方向 | 流号 | 格式 | 发送条件 |
| --- | ---: | --- | --- |
| 设备到浏览器 | 10 | PCMA / G.711 A-law，8 kHz、单声道，20 ms / 160 B | 当前查看会话有效，且浏览器已订阅音频 |
| 浏览器到设备 | 14 | PCMA / G.711 A-law，8 kHz、单声道 | 设备完成音频订阅，浏览器获得麦克风权限并发送 |

视频流 11/15 不用于本板。能力上报为无视频；上报成功不表示音频已经接通。
接口常量和格式门控见 [starter_tirtc.h](../components/starter_tirtc/include/starter_tirtc.h)，
订阅与发送检查见 [starter_tirtc.c](../components/starter_tirtc/src/starter_tirtc.c)。

## 处理链路

```text
ES7210 第一麦 + MIC3 电气回采
  → 16 kHz MR 官方单麦 AFE → 单声道增益处理
  → 抗混叠降采样至 8 kHz → 20 ms PCMA → 音频流 10

音频流 14 → 格式/代次检查 → PSRAM 固定池
  → 自适应抖动缓冲 → PCMA 解码 → 连续升采样至 16 kHz
  → 跨包 PCM 消费、微幅调速 → I2S → AW88298
```

查看与 AI、设备呼叫、微信和多人对讲复用同一采集、AEC 与播放资源。
结束查看时撤销订阅和会话所有权，停止该会话的收发与播放；常驻采集链不反复销毁。
旧代次数据不能进入下一通会话。缓冲与资源参数见[音频与资源](音频与资源.md)。

## 验证顺序

1. 平台打开实时查看并启用声音，确认浏览器能听到设备麦克风。
2. 允许浏览器麦克风权限，按住说话，确认设备扬声器播放。
3. 双方同时讲话，单独检查回声、吞字、音量和音频连续性。
4. 两端分别结束查看，再进入查看或 AI，检查旧音频、订阅和资源是否正确释放。

发送计数只证明 SDK 接纳数据；解码和 I2S 成功计数也不能代替实际听感。
本板完整双向听感、播放期间采集连续性、弱网与长稳尚未完成验收，
本板没有摄像头。H5 的接入、上行采集和下行播放按[开发指南](GETTING_STARTED_CN.md#h5-查看与对讲)分别验证，部署边界见[已知限制](../KNOWN_LIMITATIONS.md)。
