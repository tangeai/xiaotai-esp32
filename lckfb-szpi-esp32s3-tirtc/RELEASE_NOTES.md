# 版本记录

## 1.2.0

- **H5 实时查看**：接入 GC2145，按需发送 240×176、目标 12fps 的 JPEG 视频，保留双向语音；结束查看后释放摄像头。设备和微信通话仍使用语音。
- **唤醒模型**：更新模型与配套分类头，默认阈值为 0.90，窗口推进为 160ms。阈值提高后更难触发，也可能漏唤醒，可按使用环境调整。
- **能力上报**：统一上报实时查看、设备呼叫与微信通话能力，避免对端按未实现的格式发起媒体。
- **工程整理**：移除不再使用的旧页面与资源，保留现有界面；增加锁定的摄像头和 JPEG 依赖。TiRTC SDK 2.3.0、音频参数和分区布局保持不变。

完整 16 MB 固件、烧录指南与校验文件见 [1.2.0 发布页](https://github.com/tangeai/xiaotai-esp32/releases/tag/esp32-s3-app-v1.2.0)。体验平台统一为 [xiaotai.chat](https://xiaotai.chat/)。完整包会清除配网、绑定和用户设置，请先备份。

本版作为受控网络体验固件提供。H5 曾出现无首帧现象，后续反馈未复现，根因尚未证实；0.90 阈值的识别效果仍需目标板验证。构建与运行证据分别见发布页，网络认证边界见[已知限制](KNOWN_LIMITATIONS.md)。

## 1.1.2

本次公开更新包含 1.1.1 与 1.1.2 的改动，重点是配网体验、启动校时和表情动画。TiRTC SDK 保持 2.3.0，音视频配置与分区布局不变。

- **热点配网**：扫描附近 Wi-Fi，显示信号与加密状态，支持隐藏网络手填。设备记住最近 5 个成功联网的网络，再次选择时可复用密码；历史密码不返回浏览器。
- **启动校时**：每次开机联网后先完成 SNTP 同步，再开始绑定、鉴权和 TiRTC 上线。网络需允许访问时间服务器；未获得 DNS 地址时使用备用解析地址，校时等待复用同一 SNTP 服务。
- **表情动画**：提供 23 类表情、44 个姿态，增加聆听和悠闲，调整轮廓、眨眼与切换动作；思考和放松固定第一套姿态。

完整 16 MB 固件、烧录指南和校验文件见 [1.1.2 发布页](https://github.com/tangeai/xiaotai-esp32/releases/tag/esp32-s3-app-v1.1.2)。完整包会清除配网、绑定和用户设置，请先备份。

配网页使用开放热点与 HTTP，网络记录未加密存储；请在可信环境中配网。构建与目标板运行验证分别以发布页记录为准。

## 1.1.0

本版增加 TiRTC 多人语音对讲，并将 S3 工程整理为可独立构建的完整目录。TiRTC SDK 保持 2.3.0。

- **多人对讲**：创建或加入房间、可选四位密码、成员列表与按住讲话。返回菜单停止收发并保留房间关系；退出房间解除关系。操作见[多人对讲指南](docs/GETTING_STARTED_CN.md#多人对讲)。
- **存储与配网**：NVS 请求统一交给专用任务执行，Wi-Fi 名称与密码作为同一条记录保存；配置迁移与失败处理见[已知限制](KNOWN_LIMITATIONS.md#配网与版本迁移)。
- **会话与内存**：完善房间前台生命周期、AI 尾音排空和资源释放，调整 MQTT、界面及工作池的 PSRAM 使用，增加 HTTP 阶段诊断。
- **独立构建**：本目录包含代码、模型、资源和工具，不依赖 P4 或仓库根公共目录；补充主机回归与链接后检查。

完整 16 MB 固件、烧录指南和校验文件见 [1.1.0 发布页](https://github.com/tangeai/xiaotai-esp32/releases/tag/esp32-s3-app-v1.1.0)。下载后先按[首页](../README.md)完成烧录、配网和绑定，再体验通信功能。

默认配置用于受控网络评估，安全与运行边界见[已知限制](KNOWN_LIMITATIONS.md)。构建检查和目标板运行验证分别记录在发布说明中。
