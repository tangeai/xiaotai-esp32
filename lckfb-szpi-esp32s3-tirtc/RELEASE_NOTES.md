# 版本记录

## 1.1.0

本版增加 TiRTC 多人语音对讲，并将 S3 工程整理为可独立构建的完整目录。TiRTC SDK 保持 2.3.0。

- **多人对讲**：创建或加入房间、可选四位密码、成员列表与按住讲话。返回菜单停止收发并保留房间关系；退出房间解除关系。操作见[多人对讲指南](docs/GETTING_STARTED_CN.md#多人对讲)。
- **存储与配网**：NVS 请求统一交给专用任务执行，Wi-Fi 名称与密码作为同一条记录保存；配置迁移与失败处理见[已知限制](KNOWN_LIMITATIONS.md#配网与版本迁移)。
- **会话与内存**：完善房间前台生命周期、AI 尾音排空和资源释放，调整 MQTT、界面及工作池的 PSRAM 使用，增加 HTTP 阶段诊断。
- **独立构建**：本目录包含代码、模型、资源和工具，不依赖 P4 或仓库根公共目录；补充主机回归与链接后检查。

完整 16 MB 固件、烧录指南和校验文件见 [1.1.0 发布页](https://github.com/tangeai/xiaotai-esp32/releases/tag/esp32-s3-app-v1.1.0)。下载后先按[首页](../README.md)完成烧录、配网和绑定，再体验通信功能。

默认配置用于受控网络评估，安全与运行边界见[已知限制](KNOWN_LIMITATIONS.md)。构建检查和目标板运行验证分别记录在发布说明中。
